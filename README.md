# Adaptive RAG System with Google OAuth

## 🚀 Overview
This project implements an **Adaptive Retrieval-Augmented Generation (RAG)** system with:
- 📄 Document-based QA (FAISS)
- 🌐 Web fallback (Tavily API)
- 🔐 Google OAuth authentication
- 💬 Streamlit chat interface

## 🧠 Key Features
- Adaptive routing between document retrieval and web search
- LLM-based grading to decide retrieval quality
- Secure login using Google OAuth
- File upload support (PDF/TXT)

## 🏗️ Tech Stack
- FastAPI
- Streamlit
- LangChain / LangGraph
- FAISS
- OpenAI API
- Tavily API

## 🔐 Authentication
Google OAuth 2.0 is used for secure login.
